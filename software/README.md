# lsr — LibreSat Rotator head software

Tracking engine, Hamlib-compatible `rotctld`, mobile web UI and Doppler CAT control (Yaesu FTX-1, any Hamlib radio, OpenGD77 tools) for the LSR-1 rotator.

    pip install .
    lsr run --sim        # http://localhost:8080 with a simulated rotator

See ../docs/SOFTWARE.md for installation on a Raspberry Pi and all features.
