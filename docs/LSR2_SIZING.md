## 13. EL / AZ shaft decision: Mk5 M14 rod + 5x8 roll pins vs a turned keyed shaft

| Criterion | Keyed Ø14 turned 1.4404 +C700 | M14 A2-70 rod + 5x8 pin |
|---|---|---|
| Net bending / torsion modulus (mm³) | 204.6 / 474 | 51.9 / 226 |
| Static SF at gearbox peak 33.4 N·m | 3.64 | 1.68 |
| Static SF at rated 16.7 N·m | 7.03 | 3.02 |
| Fatigue SF at the operating load (Kf keyway 1.8/1.6; thread 2.8) | 4.18 | 1.75 |
| Fit and play | H7/g6 seat, P9 key: slack ~0.16 deg at the output | thread and pin hole: larger slack, pin shear 141 MPa at peak (MEASURE the pin steel) |
| Replacement | turn one shaft, press fit, keys are standard | cheapest and field-replaceable (Mk5 choice) |

**Decision: turned keyed shaft** (higher margin at the gearbox peak and a defined fit). The M14 rod is acceptable only with a torque limit <= 16.7 N·m (rated, not peak) and an inspection of the roll-pin holes. Keep the M14 rod as the low-cost fallback.
