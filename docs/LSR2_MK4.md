# BricoHams · LibreSat LSR-2: SARCTrac Mk4 replica

Authors: Anatol EA5KAO, Diego EA5JEF, Pedro Roca Molina (BricoHams).

## What it is

LSR-2 is, by default (`LSR2_DESIGN=mk4`), a **replica of the SARCNET SARCTrac Mk4** heavy az/el rotator. The mechanical design comes from the SARCNET FreeCAD files; the BricoHams work is the build pipeline, the BOM, the sizing, the firmware profile and the documentation. The earlier phase-11 cast/CNC design (own geometry, open-box body, 80:1) remains as the optional variant `LSR2_DESIGN=cast`.

## How to build

```
make lsr2                       # default LSR2_DESIGN=mk4
LSR2_DESIGN=cast make lsr2      # optional cast/CNC variant
python scripts/bom.py           # regenerates docs/BOM_LSR2.md
python calc/lsr2_sizing.py      # regenerates docs/LSR2_SIZING.md and docs/LSR2_INPUTS.md
```

`make lsr2` runs `freecadcmd` on `cad/lsr2/build.py`; the Mk4 code is in `cad/lsr2/mk4/` and reads the SARCNET files. `LSR2_RATIO` overrides the gearbox ratio (default 50 for mk4, 80 for cast). On Windows set `LSR2_OUT` to a writable folder if Controlled Folder Access blocks FreeCAD.

Outputs: laser-cut DXF files of the 2 mm cover parts in `cnc/lsr2/laser/`; STL in `stl/lsr2/`; assembly STEP; renders in `docs/img/` (`lsr2_laser_parts_real.png` shows the laser parts). Dimensioned drawings: the SARCNET PDFs in `third_party/sarctrac-mk4/FreeCAD/Drawings/`.

## Sizing summary

Mk4 defaults: ratio 50, motor 23HS32-4004S 2.4 N·m, 48 V, antennas 1270 mm, lift arms 25 SHS. 12 °/s needs 100 rpm (666.7 steps/s at 400 microsteps/rev, 0.018 ° per microstep). The report [LSR2_SIZING](LSR2_SIZING.md) must be regenerated (O30 in [OPEN_ITEMS](OPEN_ITEMS.md)). Any check below target is flagged in it and is a real shortfall: the NMRV30-G50 rating (13.0 N·m, 10.4 N·m allowed) is close to the 60 km/h wind torque, and the motor stall torque at the output (54 N·m) is above the gearbox peak, so soft limits and the mechanical end stops are mandatory.

## Electronics

```
PC (tracker) + Wemos D1 Mini (USB WiFi dongle)
        ~~~~ 2.4 GHz WiFi ~~~~
Wemos D1 Mini Pro + external antenna (SMA)   [Deltron 483-0100 housing]
   |  STEP/DIR/ENA (3.3 V -> 5 V level stage)
   +--> DM542T (AZ) --> NEMA23 23HS32-4004S --> NMRV30-G50 --> AZ
   +--> DM542T (EL) --> NEMA23 23HS32-4004S --> NMRV30-G50 --> EL
S-400-48 (48 V, indoors) --> DM542T x2 (18-50 V)
48 V --> XL7015 -> 12 V (Hall switches)
48 V --> XL7015 -> 5 V (ESP8266) --> 3.3 V LDO
NJK-5002C Hall index (NPN, active low) x2 --> controller (3.3 V pull-up)
End stops (micro switch EE-SX1103 class, saddle) --> fail-safe, in series with the driver enable
48 V --> opto-isolated power-down detect --> controller (save position)
```

Firmware (shared with LSR-1, profile LSR-2, `firmware/src/core.cpp`): ratio 50, 2 microsteps (DM542T at 400 pulses/rev), 12 °/s. Index: the NJK-5002C pulls the pin low in the magnet window (`IDX_SLOT_LEVEL 0`, `PIN_HALL_AZ` GP20, `PIN_HALL_EL` GP21; internal pull-up, 12 V sensor so the pin must be fed from the open collector only). The end stops are the hardware fail-safe: normally closed, in series with the axis ENA, so a pressed switch or a cut wire disables the driver. The firmware today has no input for them (see open items). LSR-1 behaviour is unchanged. Wiring detail: [ELECTRONICS](ELECTRONICS.md), [FIRMWARE](FIRMWARE.md).

Note: the firmware targets the RP2040 (LSR-CTL board). The Wemos D1 Mini Pro of the original Mk4 runs a different firmware; adopting it is an open decision (O35 below).

## Differences from our phase-11 cast design

| | Mk4 replica (default) | Phase-11 cast/CNC (optional) |
|---|---|---|
| Geometry | SARCNET Mk4 FreeCAD files (MIT) | own scripts `cad/lsr2/*.py` |
| Body | 10 mm plate + saddle, 2 mm laser-cut cover | open-box cast A356 or CNC body with lid |
| Gearbox | NMRV30-G50 (50:1) | NMRV030 80:1 |
| Motor | 23HS32-4004S 2.4 N·m, 4.0 A | 57BYG250H-8 2.8 N·m, 3 A |
| Antenna | 1270 mm boom, 25 SHS lift arms | 2 m class crossed Yagis |
| Controller | Wemos D1 Mini Pro (WiFi) in Deltron housing | LSR-CTL RP2040 |
| Index | NJK-5002C Hall + magnet, end stops | photo-interrupter + slotted disc |
| Output speed at 12 °/s | 100 rpm, 666.7 steps/s | 160 rpm, 1066.7 steps/s |
